How to run the project

1. Normal run 

pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000 in your browser.

2. Demo run 

To show the sample data that was generated earlier, run:

TEACHERS_DB=instance/demo.db python3 app.py

This opens the same website, but filled with ready-made demo data, which makes it easy to present.
